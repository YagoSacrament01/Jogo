# 🎯 Jogo do Número Secreto

Jogo no navegador em que você tenta adivinhar um número entre 1 e 10. A cada chute, o jogo diz se o número secreto é maior ou menor e **lê as mensagens em voz alta**.

🔗 **Jogar agora:** https://yagosacrament01.github.io/Jogo/

## Funcionalidades
- Dicas de "maior" ou "menor" a cada tentativa
- Contador de tentativas
- Não repete números já sorteados até esgotar as opções
- Leitura das mensagens em voz alta com a **Web Speech API** do navegador
- Botão de novo jogo
